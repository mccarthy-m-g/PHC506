  1. Use dplyr to add a column called delta_from_avg that contains the difference between that day’s Temp and the mean Temp of that month. Arrange the dataframe by the column you just created, in descending order (so that the relatively hottest days are listed first).
airquality |>
  group_by(Month) |>
  mutate(
    avg_temp = mean(Temp),
    delta_from_avg = Temp - avg_temp

  arrange(desc(delta_from_avg))

  1. Below are two different datetimes. How many hours apart are they? How many days apart are they? Use an argument supplied to difftime to convert units, rather than dividing by 24.
dt1 <- "2024-03-14 11:00:00"
dt2 <- "2024-03-23 19:17:00"

difftime(as.POSIXct(dt2), as.POSIXct(dt1), unit = "hours")
#> Time difference of 224.2833 hours

difftime(as.POSIXct(dt2), as.POSIXct(dt1), unit = "days")
#> Time difference of 9.345139 days
  1. Demonstrate, using the function identical, that setting a column in test_data_frame to NULL is the same as using dplyr::select to remove a column from a data frame.
test_data_frame <- mtcars

# set a column to NULL
test_data_frame$mpg <- NULL

# remove a column with select
dplyr_solution <- mtcars |>
  select(-mpg)

identical(test_data_frame, dplyr_solution)
#> [1] TRUE
