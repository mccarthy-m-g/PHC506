4.1 Lists: Flexible combinations of data

Why lists?

  • flexible, you can put anything into a list!
  • multiple data structures in one object

R will coerce elements of a vector to the same type. Sometimes we want to have multiple types of information in one object:

mixed_objects <- c("hello", 1.3)
mixed_objects
#> [1] "hello" "1.3"
a_list <- list("hello", 1.3)
a_list
#> [[1]]
#> [1] "hello"
#> 
#> [[2]]
#> [1] 1.3

Indexing into the list works a little differently. Index into the top-level elements of a list using double square brackets.

a_list[[2]]
#> [1] 1.3

Unlike vectors, each element of a list can store multiple values, including other lists. They can become very nested and variable in structure, which makes them very flexible, but also sometimes difficult to use.

b_list <- list(
  c("a", "b"),
  c(1, 2)
)
b_list
#> [[1]]
#> [1] "a" "b"
#> 
#> [[2]]
#> [1] 1 2

b_list <- c(b_list, list(c(1.3, "hello")))
b_list
#> [[1]]
#> [1] "a" "b"
#> 
#> [[2]]
#> [1] 1 2
#> 
#> [[3]]
#> [1] "1.3"   "hello"

Lists can be named, which can make them easier to work with. (Vectors can also be named but it is less commonly necessary.)

This lets us subset using the element name, which might be more easy to read and doesn’t depend on the order in which the list is defined.

canada <- list(
  population = 38250000,
  capital_city = "Ottawa",
  provincial_capital_cities = list(
    Alberta = "Edmonton",
    `British Columbia` = "Victoria",
    Manitoba = "Winnipeg",
    `New Brunswick` = "Fredericton",
    `Newfoundland & Labrador` = "St John's",
    `Nova Scotia` = "Halifax",
    Ontario = "Toronto",
    PEI = "Charlottetown",
    Quebec = "Quebec",
    Saskatchewan = "Regina"
  )
)

# with double square brackets:
canada[["population"]]
#> [1] 38250000
canada[["provincial_capital_cities"]][["Ontario"]]
#> [1] "Toronto"

# with dollar notation
canada$capital_city
#> [1] "Ottawa"

Lists are really common in statistical functions!

# example t-test for difference of means between two samples
sample_1 <- rnorm(n = 15, mean = 10, sd = 1)
sample_2 <- rnorm(n = 15, mean = 13, sd = 3)
t_test_result <- t.test(sample_1, sample_2)

t_test_result
#> 
#>  Welch Two Sample t-test
#> 
#> data:  sample_1 and sample_2

#> alternative hypothesis: true difference in means is not equal to 0
#> 95 percent confidence interval:
#>  -4.8466428 -0.3565149
#> sample estimates:
#> mean of x mean of y 
#>  10.05945  12.66103
is.list(t_test_result)
#> [1] TRUE

4.3 Functions: How things get done

R is a functional language

  • Operations are carried out with functions. Functions take objects as inputs and return objects as outputs.
    • Functions generally take arguments, some of which are often optional.
  • An analysis can be considered a pipeline of function calls, with output from a function used later in a subsequent operation as input to another function.
  • Functions themselves are objects:
median
#> function (x, na.rm = FALSE, ...) 
#> UseMethod("median")
#> <bytecode: 0x5613954059f0>
#> <environment: namespace:stats>
class(median)
#> [1] "function"
?median
# Use `median` to calculate the median of a vector, vec
vec <- rnorm(12, mean = 5)
vec
#>  [1] 5.568870 4.038834 5.986136 4.748143 3.015785 4.379115 5.544375 3.879190
#>  [9] 6.863575 5.842608 5.837660 4.345716

4.4 Getting help about a function

To get information about a function you know exists, use help or ?, e.g., ?lm. For information on a general topic, use apropos.

help(lm)
?lm

apropos("mean")

4.5 Converting between different types of objects

You can use the as family of functions.

ints <- 1:10
ints_chars <- as.character(ints)
as.numeric(c("3.7", "4.8"))
#> [1] 3.7 4.8

4.6 Be Lazy

If you’re starting to type something you’ve typed before, or the long name of an R object or function, STOP! You likely don’t need to type all of that.

  • Tab completion
    • You can skip letters when using tab completion (e.g., typing airy should give you tab completion for the airquality data set from earlier).
    • By default, tab completion starts after you have typed 3 characters. I like to change this to 2.
  • Command history
    • up/down arrows
    • Ctrl-{up arrow} or Command-{up arrow}
  • RStudio: select a line or block for execution
  • Write re-usable code! Put your code in a file and use source().

Or, create functions you can use within an analysis (more on this in lecture 4).

4.7 Common issue: incomplete code

Sometimes you write some code that isn’t a “complete sentence” and R gets confused.

(((9 + 2)) # can you spot the problem here?

The R console will show a little + sign, indicating it is expecting more.

Press escape to try again, or complete the “sentence” by adding the missing bracket.

4.8 Breakout

In general, your answers to any questions should involve writing code to manipulate objects. For example, if I ask you to find the maximum temperature, do not scan through all the values and find it by eye. Use R to do the calculations and print results.

Some of these questions will require you to search for the right function.

Hint: use the function apropos("key word") to find something to use.

  1. The variable x contains all the temperature measurements from the air quality data frame. Create a variable called ‘avg_temp’ that contains the mean temperature. Then, create a vector of length 2 that contains the minimum and maximum temperature and assign it to a variable with a meaningful name.
  1. Create a boolean (TRUE/FALSE) vector indicating whether the temperature in x is higher than the average temperature.
  1. The temperature recordings are in Fahrenheit. Convert the column to Celsius. Save the column to the data frame as a new column called “TempC” Hint: C = (F - 32) * 5/9
  1. Use functions in R to round ‘TempC’ to two decimal places and to two significant digits.
