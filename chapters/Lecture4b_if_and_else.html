We have used logical expressions before:

# logical expressions for subsetting
vec <- c(1, 5, -7, 13)
x <- vec > 0
y <- vec < 0 | vec >= 13

vec[x]
#> [1]  1  5 13
vec[y]
#> [1] -7 13

# logical expressions for subsetting in dplyr
filter(airquality, is.na(Solar.R))
#> # A tibble: 7 × 6
#>   Ozone Solar.R  Wind  Temp Month   Day
#>   <int>   <int> <dbl> <int> <int> <int>
#> 1    NA      NA  14.3    56     5     5
#> 2    28      NA  14.9    66     5     6
#> 3     7      NA   6.9    74     5    11
#> 4    NA      NA   8      57     5    27
#> 5    78      NA   6.9    86     8     4
#> 6    35      NA   7.4    85     8     5
#> 7    66      NA   4.6    87     8     6

Often you want to use logical expressions to control what code is evaluated.

For this, we will use if and else!

17.1 if-else syntax

Here’s a simple example to illustrate the syntax.

val <- rnorm(1)
if (val < 0) {
  print("val is negative")
} else {
  print("val is positive")
}
#> [1] "val is negative"

Note how RStudio colors these words differently? They are special key words.

We can chain together if statements using else if.

val <- rnorm(1, mean = 0, sd = 1)
val
#> [1] 0.1454146
if (val < -1) { 
  print("val is more than one standard deviation below the mean.")
} else if (abs(val) <= 1) {
  print("val is within one standard deviation of the mean.")
} else {
  print("val is more than one standard deviation above the mean.")
}
#> [1] "val is within one standard deviation of the mean."

In general, the { brackets are only needed if you have multiple R expressions, but R will complain when an else starts a line of code, so generally using the { is good practice. That said, this works just fine:

if (val < 0) print("val is negative") else print("val is positive")
#> [1] "val is positive"

# better:
if (val < 0) {
  print("val is negative") 
} else {
  print("val is positive")
}
#> [1] "val is positive"

17.2 The condition in an if statement

There are two rules for the if () statement:

  1. The value evaluated must be TRUE or FALSE

    • NA, NULL, and NaN will all produce (different) errors

  2. The value evaluated must be of length 1

    • If more than one value is provided, depending on your user settings, either the first value will be evaluated or you will encounter an error
    • If less than one value (c() is of length 0), you will encounter an error

Zero evaluates to FALSE, all other numbers evaluate to TRUE. In general strings are not converted to booleans.

# These will both produce errors
vec <- c(4, 8)
vec < 6
#> [1]  TRUE FALSE
if (vec < 6) {
  print("vec is less than 6")
} else {
  print("vec is not less than 6")
}
#> Error in `if (vec < 6) ...`:
#> ! the condition has length > 1

vec <- NA
if (vec < 6) {
  print("vec is less than 6")
} else {
  print("vec is not less than 6")
}
#> Error in `if (vec < 6) ...`:
#> ! missing value where TRUE/FALSE needed

If you anticipate missing data, a more robust alternative is to use isTRUE():

isTRUE(NA)
#> [1] FALSE
isTRUE(NULL)
#> [1] FALSE
isTRUE(1)
#> [1] FALSE
isTRUE(FALSE)
#> [1] FALSE
isTRUE(TRUE)
#> [1] TRUE
isTRUE(as.logical(1))
#> [1] TRUE

vec <- NA
if (isTRUE(vec < 6)) {
  print("vec is less than 6")
} else {
  print("vec is not less than 6")
}
#> [1] "vec is not less than 6"

If you want to be able to handle vectors, all or any are helpful:

# `any` checks for at least one TRUE
vec <- c(4, 8)
if (any(vec < 6)) {
  print("at least one value is less than 6")
} else {
  print("no values are less than 6")
}
#> [1] "at least one value is less than 6"

# `all` requires every value to be TRUE
vec <- c(4, 8)
if (all(vec < 6)) {
  print("all values are less than 6")
} else {
  print("at least one value is not less than 6")
}
#> [1] "at least one value is not less than 6"

17.3 Vectorized if/else

Sometimes it is helpful to use this same if...else... logic in a vectorized way, i.e., to apply different operations on a vector according to some condition

For this, we can use ifelse.

For example, we have a number of patient lab results, and we want to indicate which lab results were normal versus elevated:

bilirubin <- data.frame(
  pt = c("M.H.", "P.J.", "K.G."),
  lab = c(1, 1.8, 0.7)
)

bilirubin
#> # A tibble: 3 × 2
#>   pt      lab
#>   <chr> <dbl>
#> 1 M.H.    1  
#> 2 P.J.    1.8
#> 3 K.G.    0.7

Elevated bilirubin is defined as a value above 1.2:

mutate(
  bilirubin,
  bilirubin_test = ifelse(lab > 1.2, "elevated", "normal")
)
#> # A tibble: 3 × 3
#>   pt      lab bilirubin_test
#>   <chr> <dbl> <chr>         
#> 1 M.H.    1   normal        
#> 2 P.J.    1.8 elevated      
#> 3 K.G.    0.7 normal
